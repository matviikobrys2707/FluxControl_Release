Оновити код підключення?

Поточний код і QR-код перестануть діяти одразу. Це вплине на інших:

користувачі, які додали цей ПК за старим кодом, втратять доступ — пристрій стане недоступним;
старе пряме посилання покаже помилку «код невірний»;
щоб підключитися знову, треба ввести новий код або відсканувати новий QR.

Помилка:

Якщо завантажили вручну — розпакуйте ffmpeg.exe у папку %AppData%\FluxControl\ffmpeg або поруч із FluxControl.exe та натисніть «Перевірити ще раз». Постійна папка не зникає після пересборки програми.
